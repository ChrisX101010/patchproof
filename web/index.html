    NO PIPELINE. NO ALWAYS-ON SERVER.

    Three services. One portable proof.

    A single Lambda serves the interface and API. S3 keeps the immutable capsule; DynamoDB keeps the small report index.

    01 / COMPUTE

    AWS Lambda

    On-demand HTTP requests through a Function URL. No VM, load balancer, VPC or deployment pipeline.

    02 / EVIDENCE

    Amazon S3

    Private, content-addressed capsules. Conditional writes keep repeated publication immutable.

    03 / DISCOVERY

    Amazon DynamoDB

    A bounded report index. Retrying a publication repairs an interrupted index write.
